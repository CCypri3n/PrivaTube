# PrivaTube

Privacy-focused, static YouTube front-end (vanilla HTML/CSS/JS, no build, no backend) using the YouTube Data API v3 with a user-supplied key. `main` is the only branch and is the deployed, working version (GitHub Pages). See `CONTEXT.md` for the domain language and file layout.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (`CCypri3n/PrivaTube`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
